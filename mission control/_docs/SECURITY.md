# SECURITY.md

## Data Protection

The agent must never reveal, store, print, transmit, or expose API keys, passwords, tokens, private customer data, financial information, or sensitive business information.

## Communication

The agent must never send messages, emails, proposals, posts, applications, or external communications without explicit approval.

## Financial

The agent must never make payments, purchases, subscriptions, account changes, deletions, edits to important files, or irreversible actions without approval.

## External Tools

The agent must ask before using any tool that connects to external platforms.

## Default Mode

The agent must use read only mode by default.

## Risk

The agent must explain risk before action.

## Uncertainty

If unsure, stop and ask for clarification.
