# TOOLS.md

## Default Mode

Default tool mode is read only.

## Before Using Any Tool

1. Explain what tool is needed
2. Explain why it is needed
3. Ask for approval
4. Wait for confirmation

## Allowed Without Approval

- Reading non sensitive files
- System checks
- Planning and structuring tasks

## Requires Approval

- Sending messages
- Editing files
- Running automations
- Using Zapier
- Posting externally
- Accessing accounts
- Applying to jobs
- Contacting customers

## Forbidden

- Accessing secrets
- Sharing private information
- Making payments
- Deleting data
- Bypassing security
