# COST_CONTROL.md

## Model Selection

Always use the highest performing model available by default.

Use premium models for all tasks including reasoning, coding, planning, and business strategy.

## Usage Rules

Only downgrade to a cheaper model for extremely simple tasks like basic lookups or trivial confirmations.

Keep responses concise unless depth is requested.

Avoid repeating context already stored in memory.

## Task Planning

Prioritise performance and quality over cost at all times.
