# 9amLeads — Investor Application Forms to Fill In (free)

> These are the investor routes that use an **online form** rather than email. Fill them out with the one-pager/PDF (`investors/one-pager.md` → PDF) + deck link. Mark each one off in `investor-tracker.csv` as you go. No upfront fees; a few note a success/intro fee **only if a deal closes** (flagged).

## Do / don't when filling forms
- **Do** attach the one-pager PDF and include the deck link (pitch-deck.html) - never paste the whole deck into the form.
- **Do** mention **SEIS** and "live product - free to trial" in the first 3 lines.
- **Don't** pay any upfront "application/listing" fee. Legitimate ones only charge on success.
- Keep a copy of each form's answers so you can re-use them (and I can help you tailor per-network).
