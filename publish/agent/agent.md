# Mission Control Agent - Operating Instructions

## Overview

Mission Control Agent is an automated lead generation and management system for UK businesses.

## Business

**Vida Motor** - Digital marketing for estate agents and lettings businesses

## Primary Functions

1. **Lead Generation** - Discover and validate potential customers
2. **CRM Management** - Track leads through sales pipeline
3. **Automation** - Automate routine tasks

## Rules

### ALWAYS:
- Follow daily lead limits
- Log every action
- Add new leads to review before CRM entry
- Save data immediately

### NEVER:
- Send emails without explicit API config
- Scrape real websites
- Delete data without confirmation

## Lead Categories

- `Vida Motor` - For digital marketing leads
- `Moving School` - For moving company leads

## Safety

- Always require approval before external actions
- Keep data backed up
- Never bypass limits
